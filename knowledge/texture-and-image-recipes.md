# テクスチャ / 画像加工のレシピ (UV テクスチャを自動で加工した記録)

実装は `tools/texture/`。どれも node + ffmpeg の raw RGBA パイプライン (4096x4096 を数秒〜十数秒で処理)。パラメータはスクリプトの先頭か引数で変える。

## 共通の流れ
1. 元 PNG を作業フォルダにコピー (元は読み取り専用で触らない)。
2. `ffmpeg -i src.png -f rawvideo -pix_fmt rgba src.rgba` で raw にし、node で加工して `out.rgba` を書く。
3. `ffmpeg -f rawvideo -pix_fmt rgba -s 4096x4096 -i out.rgba out.png` で PNG に戻す。サイズ・形式 (RGBA / RGB) は元と同じにする (「画質はそのまま」の依頼が多い)。
4. 縮小プレビュー (`-vf scale=1400:-1`) と、気になる所の等倍クロップを両方作って自分で見る。
- ffmpeg は PATH に無いことがある。フル機能のものを探す (overlay が必要なとき)。

## UV 島の抽出 (`uv-island-extract.js`)
- UV テクスチャは、背景が一様な灰色で、島 (パーツ) が離れて並ぶ。背景色との差で前景マスクを作り、連結成分 (4 近傍) にラベルを付け、目的の島の内部の 1 点 (シード) が属する成分だけ残す。
- 島の内側の穴 (背景色と同じ色の閉じた領域) は、「境界から到達できる非対象」を塗って、残りを島の内部とみなして埋める。
- 出力: 対象島だけ残して他は透明 (アルファ 0) にした PNG、同じ範囲を白にした白黒マスク (lilToon のマスク系スロットに使う。sRGB は OFF)。
- 注意: どの島が「目」かは目で見て決める。小さい島 (瞳、ハイライト) が必要か分からないときは外して、後で足せると伝える。

## 絵・ロゴの削除 (`inpaint-ellipse.js`)
- 衣装の刺繍ロゴなどを消すときは、ロゴの bounding box (暗い画素の範囲を実測) から楕円を決め、その内部を Jacobi 拡散 (周囲の画素を内側へ平均していく) で埋める。布のグラデーションが緩やかなら跡が出ない。
- 色テクスチャだけでなく、ノーマルマップ・AO など、同じ位置に絵が入っている他のテクスチャも同じ楕円で処理する (ノーマルマップに刺繍の凹凸が残る)。
- 別の島にある同じ絵 (肉球パーツそのもの) は、テクスチャで消すとメッシュが無地になるだけ。メッシュ側の非表示が要る。

## 線画からノーマルマップ (`lineart-to-normal.js`)
- 黒い線を溝として扱う: 溝の深さ = 暗さ (黒インクで 1)、彩度の高い線 (赤アクセントなど) は 0.35 の浅い溝。細い溝 (σ 1.6) + 広い面取り (σ 7 の 0.35 倍) の高さマップを作り、Sobel の勾配から法線にする。勾配の 99.5 パーセンタイルが 55 度になるように強度を自動正規化する。
- 向きは Unity の OpenGL 方式 (緑が上)。画像座標の y を反転する。線の無い所は (128,128,255) で完全に平ら。
- 出力は 4K のまま使う: 細い線 (1〜6 px) は 2K に縮小すると陰影が消える。インポート設定は Normal map、Compression は High Quality (Normal quality だと斜面にブロックノイズ)。
- 確認: 元の線を軽くのせた「ライティング済みプレビュー」を作って見る。

## 汚れと血の痕 (`dirty-and-blood.js`)
- 背景 (純白) を画像の端からの塗りつぶしで特定し、それ以外 (島の内側) だけ加工する。背景は純白のまま。
- 汚れの層: 黄ばみ (大きなノイズの高い所に茶色の乗算)、縁の汚れ (島マスクをぼかして 1 から引く)、裾への汚れ (y 方向のグラデーション)、シワの谷への汚れ (元の明るさが暗い所)、水染み (弱い輪郭)、布目。元のシワの陰影は残す。
- 血: ドメインワープした円の合成 (縁をギザギザに)、垂れ (細い筋の先に玉。付け根は血だまりの内側から始める)、飛沫。色は鮮やかな赤ではなく乾いた赤茶 (縁は濃く茶色)、元の布の明るさで陰影を残す (血の内側にシワが透ける)。絵の具のように見えたら、色を落として明るさの変動を足す。
- 血なし版は同じスクリプトで血の係数を 0 にする (汚れだけ欲しいという依頼もある)。

## 画像加工で踏んだ罠
- SVG は headless Chrome でラスタライズする (フォントが無い環境でも形は出る)。
- 位置合わせは「縫い目の中心に S が来るように」など、目で確認できる基準で追い込む。依頼の言葉 (「もう少し右」「1.1 倍」) は段階的に直し、その都度プレビューを見せる。
- 折り目に合わせた歪みは、ぼかした輝度から変位を作る。
- 元の画質を保つときは、再エンコードを 1 回だけにする (PNG → raw → PNG)。JPEG を挟まない。
