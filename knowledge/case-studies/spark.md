# SPARK 実機で確認が必要な点 (2026-10-19 改修後)

操作 (両手の組み合わせ)
1. 右手グー (構え) + 左手ジェスチャーで技が出るか。構えなしの左手開きで球電だけが出て、構え + 開きで落雷に切り替わるか。
2. 構えの右グーと、チャージの両手グーが衝突しないか (放電済みのときだけ Charging に入る)。
3. チャージ完了後、右手を握ったままで技が暴発しないこと (Rest は ArmParam != 1 を待つ)。
4. 表情ギミックと同じジェスチャーを使ったとき表情が同時に変わる (仕様)。

見た目
5. 3 パス (ハロー / 1 フレーム残光 / 芯) の稲妻が「綺麗」か。残光パスの 1 フレーム遅れが VR の 90 fps で見えるか。
6. 細い糸状の枝 (BranchLen、Width 0.15-0.2) が遠目で潰れないか。細かさ (detail) 1.0 の負荷。
7. 落雷: 先駆放電 (StrikeLeaders、0.02-0.16) → 本撃 (0.11) の順が分かるか。土煙 (StrikeDust) が火花色なので違和感がないか。
8. 雷球 (Shot): 手の子オブジェクトの localPosition を腕方向に 6 m 動かしている。発動後に手を動かすと球も追従する (仕様)。壁抜け。
9. 全方位の雷の柱 6 本 (FX ルート基準、天から 7 m) が室内で天井を抜けないか。
10. 指先アーク (FingerArcs、Distal 骨間) と目の発光 (Eye 骨 +1.2 cm 前) が顔に埋まらないか。Velnica 素体には指骨あり (テストで生成確認)。
11. 残り火 (Embers、Billboard、noise) が静かな場所で浮いて見えないか。
12. 落雷の着地点: VRCPositionConstraint (AffectsPositionY=false)。発動中は Constraint を止めて固定。

音 (CC0 実録を SparkSoundPrep で切り出し)
13. 低い音になったか。thunder 5 秒 / discharge 1.4 秒 / hum と crackle のループ継ぎ目 / charge 5 秒 / ballburst 1.6 秒。音量バランス (volume 0.55、落雷のみ距離 1.6 倍)。
14. ループ素材の継ぎ目 (0.35 秒クロスフェード) が気にならないか。

その他
15. 熱ゆらぎ (GrabPass) が強すぎないか。VR 両目で正しく出るか。
16. 点光源 3 つ (手 / 落雷点 / 雷球) が相手側で見えるか。
17. 移動中の足元火花と両脚アーク、着地リング (VelocityY < -3 → Grounded)。
18. 三角形約 23,000 (全稲妻合計、同時表示は最大でも落雷時の 4 メッシュ程度)。Skinned Mesh 22 の Poor 判定は許容 (他ギミックと同時でも Very Poor 止まり)。
