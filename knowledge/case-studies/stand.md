# STAND 実機で確認が必要な点 (2026-10-16)

1. スタンドの腰: HipsProxy (本体腰を世界座標で追従) → スタンド腰は SolveInLocalSpace=true で「本体ルートに対する腰の相対姿勢」を写す想定。SolveInLocalSpace の意味が想定と違う場合、スタンドの腰が変な位置に出る。代替案: 腰も世界座標 Parent Constraint にして、オフセットを腰ローカルで近似する。
2. Rotation Constraint の RotationOffset の掛かり方 (別アバターのとき)。自分自身のスタンドではオフセット 0 なので影響なし。別アバターで腕がねじれる場合はオフセットの合成順を逆にする。
3. T ポーズ揃え (HumanPoseHandler で筋肉値 0) がビルド中に正しく当たり、ビルド後に元の姿勢へ戻っているか (NDMF のクローン上で実行)。
4. 上半身凍結: 出した瞬間に上半身が止まり、下半身は動き、しまうと戻るか。腰の継ぎ目の見え方。表情ギミック (本体の元メッシュの BlendShape) が隠れている間だけ効かないのは仕様。
5. 他ギミックとの同居: ZANZO の残像がスタンドや凍結コピーを拾わないか (シェーダー名除外は STAND/ のみ。凍結コピーは元のマテリアルなので ZANZO の残像対象に入る可能性がある → 実機で確認し、必要なら名前 (FrozenUpper / _STAND_Lower) で除外)。
6. 配色・縮約の見た目 (2 万三角形で十分か、顔が潰れすぎないか)。
7. 粒子・効果音・前後切替 (Sources.source0.ParentPositionOffset のアニメーション)。
