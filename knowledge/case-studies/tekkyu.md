# TEKKYU 実機で確認が必要な点 (2026-10-20 初版)

位置と挙動
1. 手のひらの上の位置: T ポーズで手のひらが下を向く前提で、手ボーン + 腕方向 7 cm + 手のひら側 (半径 + 1.2 cm)。Velnica 素体以外でずれないか。回転中はさらに 4.5 cm 浮く。
2. 投擲: VRCParentConstraint (手に追従) を Throw / Curve 中だけ IsActive=0 にして固定し、その子を localPosition で動かす。固定した瞬間の腕の向きに約 5 m 飛ぶ。IsActive=0 で本当にその場に止まるか (SPARK の落雷点は PositionConstraint で確認済み、ParentConstraint は未確認)。
3. 投擲中に手を動かしても軌道は変わらない (仕様)。戻ってきた瞬間に手元の鉄球に切り替わる (Catch 0.3 秒) ので、手を大きく動かしていると瞬間移動して見える。
4. 曲射の軌道 (前方 4 m、横 2.5 m の弧、往復 2.2 秒) が室内で壁を抜けすぎないか。
5. Twin → SpinDown で反対の手の鉄球が即座に消える (縮小演出なし)。気になるなら TwinDown を足す。
6. 回転中に指差し → 投擲 の遷移で、コントローラーのジェスチャー切り替えが中間値 (None など) を経由すると SpinDown に落ちて投げられないかもしれない。実機で頻度を見る。

見た目
7. 鉄球シェーダー: 格子の溝 (36 × 18)、回転時のモーションブラー (7 サンプル)、反射プローブの映り込み、縁の発光。Bloom のないワールドでの見え方。溝が細かすぎて遠目で潰れないか。
8. 渦巻き線 (5 本、半径 1.18〜1.3 倍、Y 軸回転 5 回転/秒 + 揺れ) がアニメの「白い細い線」に見えるか。太さ半径 × 0.16。
9. 傾いた光の輪 (直径 6.4 倍、28 度傾き、明るい弧が回る) の見え方。
10. 風の筋 (軌道パーティクル 40/秒) が多すぎないか。
11. 黄金の軌跡 (TrailRenderer 0.35 秒、幅 2.4 倍) が投擲の速さで途切れないか。戻りでも引く。
12. 着弾: 土煙の渦 (55/秒 + 30 バースト、orbitalY 5)、火花 50、衝撃の輪 2.2 m、閃光、空気のゆらぎ 2.2 m。土煙が空中でも出る (地面判定なし) ので浮いて見えるか。
13. 二球の黄金の放射光 (直径 14 倍、光線 16 本) が大きすぎないか。

音
14. 回転ループはシンギングボウルの実録 (352611) を 847 Hz に再ピッチし、3.2 Hz の AM と 627 Hz の再ピッチ副音を重ねたもの。アニメの音として聞こえるか。tools/out/tekkyu_listen に bowl_a / bowl_b / glass_a / glass_b / glass_c の候補を並べてあるので耳で選ぶ (選んだら tools/tekkyu-sounds-rec.js の VARIANT 既定を変えて再生成)。
15. 投擲中は投げた鉄球側にも回転ループ (別の AudioSource) があり、距離で減衰する。手元のループは Throw 中は止まる。
16. ループの継ぎ目 (実録を 0.4 秒クロスフェードで 2.5 秒ループにしている。AM とうねりは 2.5 秒の整数周期)。継ぎ目で音色が変わって聞こえないか。
17. 出現 / 消失 / 受け止め / 着弾 / 投擲 / 戻り の音量バランス。着弾は距離 1.5 倍。
