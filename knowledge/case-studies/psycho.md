# PSYCHO (目がブレる) の事実と未確認事項 (2026-10-30、v1.0.0)

## 確認済み (エディタ)
- ユーザーの依頼: サイバーサイコシスの「目がブレる」演出だけが欲しい (CYBERPUNK: EDGERUNNERS の静止画を参照)。VRChat のアバターでは画面全体のポストエフェクトが使えないので、眼球メッシュを複製してシェーダーで画面空間にずらす方式。
- 眼球の見つけ方: Humanoid の LeftEye / RightEye ボーン (無ければ Head 配下の eye を含む名前のボーン) に重み minBoneWeight (0.5) 以上で付いている頂点だけの三角形。
  Velnica (Face メッシュ、832 三角形)、Milfy (Body メッシュ、3856 三角形、2 材質) で検出できた。別のアバターの FBX はこのプロジェクトでは Humanoid 設定でないためテスト対象外。
- 複製メッシュ: 眼球の頂点だけを (枚数 + 1) 回並べ、uv2.x = 何枚目か。ボーンウェイトと bindposes は元のまま、bones / rootBone を共有する SkinnedMeshRenderer を `PSYCHO_Eyes/PSYCHO_<元のメッシュ名>` に置く。ブレンドシェイプは複製していない。
- シェーダー PSYCHO/EyeGhost: 頂点で `floor(time * rate + i * 0.37)` ごとに hash で xy オフセット (view 空間、m)、確率で非表示、たまにバースト (2.4 倍)、`vp.z += _Pull` でカメラ側へ浮かせる (view 空間は -z が前)。0 枚目は元の目の震え (0.18 倍、常に表示、薄い赤)。Transparent+20、ZWrite Off、ZTest LEqual、Cull Off、インスタンシングと STEREO マクロ入り。`_TimeOverride` >= 0 で時刻を固定 (プレビュー用)。
- テクスチャ: 元材質の _MainTex をそのまま参照。テスト FBX には無いので白にフォールバック (プロパティ既定値 "white")。
- プレビュー review/psycho/sheet*.png: OFF と 4 時刻。両アバターで残像が左右に 2〜5 cm ずれて赤く重なる。

## 未確認 (実機)
1. 他人からの見え方 (時刻は _Time なので各クライアントで別の乱数になる。「同じ動き」ではなく「同じ種類の動き」。同期させたいなら時刻を同期パラメータで送る必要がある)。
2. VR での見え方 (左右の目で UNITY_MATRIX_MV が違うので、残像の位置が左右の目で一致しない可能性。ずれが大きいと立体視で浮いて見えるかもしれない)。
3. 自分の一人称: 眼球は頭の中なので見えない想定。鏡では見える想定。
4. まぶたを閉じたときに残像が目の上に乗る。
5. Milfy の眼球メッシュに含まれる細い筋 (まつ毛かハイライト) が一緒にブレる。
6. VRCFallback=Hidden なので、シェーダーが許可されていない相手には残像が見えない。
