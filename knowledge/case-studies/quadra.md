# QUADRA (車) の事実と未確認事項 (2026-10-26、v1.0.0)

## 確認済み (エディタ)
- 元モデル: 外部の glb モデル (Sketchfab、Sketchfab Standard 表記)。13.8 万三角形 / 70 材質 / 147 画像 (すべて 1024) / アニメ 6 (左右ドア・ボンネット・トランク・左右窓)。
- glb は前が -Z。z 反転で Unity の +Z が前。原点は車軸の高さ (y=0)、接地は y=-0.378 (後輪)。前輪半径 0.347 / 幅 0.375、後輪半径 0.378 / 幅 0.646 (前後で径が違う)。全長 4.8 m、全幅 2.4 m、屋根 y=0.92。
- メッシュノードは Object_N という名前で、意味のある名前 (ext01_door_l_01__101 など) は親ノード。分類は親の名前で行う (tools/quadra-dump.js の nameOf)。
- 左ハンドル。運転席 x=-0.38、助手席 x=+0.38。座面と背もたれは断面図 (review/quadra/section_driver.png、x=-0.38 で切った正射影 + 0.25 m 格子) で実測: 腰の位置 (-0.38, 0.13, -0.34)、座面上面 y≈0.04、背もたれは垂直から約 16 度、ペダル z≈+0.2 y≈0.1、天井の内側 y≈0.75。最初に置いた z=-0.62 は背もたれの約 20 cm 奥で、腰が座面の下に沈んでいた。
- ドアはヒンジ回転ではなく「後ろ上へスライドしながら傾く」: 左ドアは開いた姿勢で位置 (-0.095, +0.438, -1.187)、回転 約 25.6 度 (glb のアニメのピーク、Unity 座標に変換済み)。インポーターはこの開いた姿勢を DoorL_Open / DoorR_Open という補助オブジェクトとして Prefab に入れ、ビルダーが読んで消す。
- テクスチャは ゲーム由来の塗り分けマスクで、塗装色は含まれていない (外装のベースは黒地にグレーと黄土色の斑)。アトラス生成時に彩度の低いグレー斑を黒へ、彩度のある黄土色を明るく (金のライン) 処理している (tools/quadra-atlas.js の paint)。glb の法線・粗さマップは別 UV (tc1, tc2) を使い、中身もほぼ平坦なので使っていない。
- アトラス 4096x2048 (ユーザーの指示「テクスチャはアップロード時にこちらで処理するので極力高品質に」): 外装・内装・後輪リム・前輪リム・シャシー各 1024 (縮小なし)、タイヤのトレッド (タイル 3 回) 3072x1024。ナンバーは外装セルの暗い点を参照。インポート設定は BC7 / CompressedHQ / 品質 100。
- ランプは 4x1 の色見本 (暖白・白・琥珀・赤) を UV で指す 1 材質。ガラスは透明 2 材質 (無色・赤)。全部で 4 材質、スロット 12、Renderer 7。
- 縮約はノードごとに目標三角形数 (QuadraImport.cs の BodyTargets、ドア 0.7、タイヤ 0.8)。合計 4.5 万。
- ユーザーの指摘 (2026-10-26): 「テカテカ & テクスチャ粗すぎ」→ 滑らかさ 0.3 / 金属 0 / 反射色 0.2、アトラスを等倍化、金ラインの境界をくっきり (彩度のしきい値を狭く)。
- 位置ディゾルブの「OFF」は border=-20 (車は全長 4.8 m なので、バイクの -2 だと後ろ半分が常に溶けていた)。
- 姿勢: QuadraPoseSolver (KUSANAGI と同じ椅子方式) に背もたれ角 recline (初期 18 度、RootQ を後ろへ倒す) を追加。足は腰から (-0.08, -0.04, +0.54) を目標。Velnica は届く、Milfy は z≈+0.2 まで届く (どちらも頭は天井の下、頭ボーン y 0.41 から 0.51)。

## 未確認 (実機)
1. KUSANAGI の未確認 1〜4 と同じ (駐車 = IsActive 0、呼び出しの同期、乗車時の腰の位置、Action / Tracking)。
2. 降りるとき: Dismount で Constraint を summon アンカー (右横の止まる位置) に戻してから IsActive 0。車が右横に移ってから残るか。
3. 助手席 Station: 他の人が Use で座れるか (trigger の BoxCollider 0.75x0.7x0.9)、座った人の腰が座面 (passengerOffset y=0.04) に来るか (Station の位置とアバターの腰の関係は実機依存)、走行中に追従するか、降りると右側 (x=+1.8) に出るか。
4. 前輪の切れ角: AngularY > 45 で右 20 度、< 22 で戻る (0.3/0.4 秒)。符号が実機で逆なら Steer の値を反転。
5. タイヤの回転: 前後で半径が違うので Wheels F / Wheels R の 2 レイヤー。VelocityZ で速度、1 m/s で 1 周 / 円周。
6. ドア: 乗る/降りるの 1.1 秒で左ドアが開いて閉まる。他人にも同じに見えるか (同期 bool から遷移するので見える想定)。
7. 背の高いアバターで頭が天井から出るか (Velnica / Milfy は収まる)。出るなら「大きさ」を上げる案内を README に書いた。
8. 素材の利用条件 (Sketchfab Standard、ゲームの車両デザイン、ゲーム UI 音) は未確認。効果音は KUSANAGI と同じ 5 つを流用。
