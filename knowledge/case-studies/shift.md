# SHIFT (重力シフトの見た目) の事実と未確認事項 (2026-11-02、v1.0.0)

## 確認済み (エディタ)
- ユーザーの依頼: GRAVITY DAZE の重力シフトを「見た目だけ」で。衣服や髪の重力が上を向く、赤くなる。移動・重力そのものは不要 (コライダージャンプ案は却下)。
- 構成: PhysBone の gravity / gravityFalloff をアニメーションで書き換え (ON: -upGravity / 0、OFF: 元の値)、体の各 Renderer と同じメッシュ・ボーンのコピーに加算シェーダー SHIFT/Aura、腰に付けた箱から上へ流れる赤い筋のパーティクル (SHIFT/Streak、Stretch ビルボード)。ON/OFF の遷移は 0.25 秒ブレンド。
- オーラは最初 1.2 cm 浮かせた殻で作ったら、服の下の体の殻まで表に出て全身が真っ赤に透けた。殻を 3 mm に密着させ、Offset -1,-1 + ZTest LEqual で深度に負けるようにし、強さを下げたら輪郭の赤い光 + 薄い赤の膜 + 流れる筋になった (review/shift/on_t1*.png / on_t2*.png、off*.png)。
- 筋パーティクルは最初 (寿命 0.9 s、velocityScale 0.12、太さ 2 cm) だと画面を縦断する太い棒になった。寿命 0.25〜0.5 s、velocityScale 0.06、太さ 4〜11 mm、本数 45/s で細い線になる。
- テスト (ShiftDevTest.RunBatch): Velnica (オーラ 14 メッシュ) / Milfy (26 メッシュ)、テスト用に頭の子ボーンへ PhysBone 2 本 (gravity 0.2/0.3 と 0/0) を足して、ON クリップが全 PhysBone に -0.4 / 0、OFF クリップが元の値を書くこと、ホルダーと筋が既定 OFF、メニューとパラメータ、バインディング解決を確認。
- 試験用 FBX は素体なので PhysBone 無し。本物のアバターでの PhysBone 数は未計測。

## 未確認 (実機)
1. PhysBone の gravity をアニメーションで書き換えたとき、VRChat 内で実際に髪が上へ上がるか、他人視点でも同じか。MONOWIRE では PhysBone をビルド時に作るだけで、値のアニメーションは今回が初。動かない場合の代替は「上向き重力の PhysBone を別コンポーネントとして複製し、有効/無効を切り替える」方式 (切替時に髪が一瞬リセットされる)。
2. 加算オーラの見え方 (lilToon の髪の透過部分と殻の前後関係、暗いワールドでの眩しさ)。
3. 筋パーティクルの量・長さの実機での印象。
4. 髪が頭に刺さるアバターがあるか (上向き 0.4 の強さ)。
5. 名前 SHIFT は仮。ユーザーの承認待ち。
