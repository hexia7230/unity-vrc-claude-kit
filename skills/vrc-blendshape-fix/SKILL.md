# ブレンドシェイプの重ね掛けの崩れを直す

## 原因の見立て (まず疑うこと)
1. シェイプキーは足し算で、合計に上限が無い。細めた顔にまばたきを足すと閉じきりを越える。
2. 表情の State に Tracking Control (Eyes = Animation) が無いと、自動まばたきが重なる。
3. 目の大きさ・位置のシェイプ (`face_eye_*`) を変えていると、元のまばたきの移動量が大きすぎる。
4. 表情クリップが元シェイプを毎回上書きしている (0 を書く)。

## 調査の手順 (読み取りだけで再現する)
1. 利用者の実際の値を取り出す: シーンの Prefab 上書き (`m_BlendShapeWeights.Array.data[i]` の `value`) を node で読み、インデックスをメッシュのシェイプ名に対応づける。ユーザーのプロジェクトは変更しない。
2. 付属のクリップ (FX の表情・ジェスチャー) をテスト用フォルダへコピーし、書いている値を見る。FX の State と Tracking Control の有無もコントローラーから読む。
3. バッチで、利用者の値 + 付属クリップで「修正前 / 修正後 / 無改変」を描画する (`skills/unity-preview-render`)。片目ずつ、複数の表情 (自動まばたき、グー、ピース、笑顔) の列で並べる。
4. 数値でも確認する: 閉じ目の頂点位置の最大誤差が 0 mm になるか。

## 修正の実装 (詳細は `knowledge/blendshape-and-mesh-methods.md`)
- 元シェイプ (今の値 ≠ 0 の目まわり) の逆デルタを、閉じる系シェイプ (幾何で判定) に焼き込む。片目シェイプは頂点の x の符号で側を分ける。
- FX が書く元シェイプは素体に焼き込む。
- 目を閉じる State に Tracking Control (Eyes = Animation) を足し、同レイヤーの他の State に Tracking を足す (NDMF AnimatorServices、MA の後)。
- シェイプの順番・名前・数は変えない。Renderer の値は変えない (焼き込んだものだけ 0)。
- 設定は無し (Prefab を置くだけ)。専用モデルなら名前の接頭辞で絞ってよいが、判定は幾何で。
