# テクスチャ / 画像の加工

## 前提
- 元のファイル (ユーザーのアバタープロジェクト内) は読み取り専用。作業フォルダにコピーして加工し、結果は Downloads などに別名で出す。
- 「サイズはそのまま」「画質はそのまま」が基本。PNG → raw RGBA → PNG の 1 往復だけにする。サイズと形式 (RGBA/RGB) を元と揃える。
- 先に `knowledge/texture-and-image-recipes.md` を読む。実装は `tools/texture/`。

## 手順
1. 元画像を開いて見る (縮小プレビュー + 該当部分の等倍クロップ)。ヘッダ (幅・高さ・色タイプ) も確認する。
2. 目的に合うスクリプトを選び、コピーしてパラメータを直す:
   - 島の抽出とマスク: `uv-island-extract.js` (シード座標は目で決める)。
   - ロゴ削除: `inpaint-ellipse.js` (暗い画素の bounding box を実測して楕円を決める。色・ノーマル・AO を同じ楕円で)。
   - 線画 → ノーマル: `lineart-to-normal.js`。
   - 汚れ / 血: `dirty-and-blood.js`。
   - glb のアトラス: `tools/glb/`。
3. 出力を PNG に戻し、ビフォー・アフターを並べて自分で確認する。島の外 (背景) が 1 ピクセルも変わっていないことも数値で確認する (`changed bytes` が想定の範囲内か)。
4. 出力先を報告する。使い方 (Unity のインポート設定: ノーマルは Normal map + High Quality、マスクは sRGB OFF、アルファ付きは Alpha Is Transparency ON) も書く。
5. 関連する別テクスチャ (ノーマル、AO、色違い) に同じ絵があるときは、必要なら同じ処理をかけると伝える。メッシュ側にしか手段が無いもの (別の島にある同じ絵) は、できないと伝える。

## 注意
- ffmpeg / node / ImageMagick のうち、環境にあるものを使う。`python` はスタブのことがある。
- 結果が納得いかないときは、パラメータを 1 つずつ変えて撮り直し、変更点を書く。
