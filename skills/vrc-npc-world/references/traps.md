# 踏んだ落とし穴 (同じ所で転ばないために、先に読む)

## キャラクターと動き

- **AFK モーションで固まる。** アバター付属の AFK モーション (うつむいて手を後ろ) は、変な姿勢で固まって見える。使わない。
- **ずっと目を閉じたままになる。**
  - 付属の `blink.anim` は「目を閉じた 1 コマ」の静止画だった。層にそのまま使うと閉じたままになる。
  - 閉じて開く 0.16 秒のクリップを作り、まばたきの間だけ層の重みを 1 にする。
- **`OnAnimatorIK` が一度も呼ばれない。** `AnimatorController.layers` はコピーを返す。`iKPass` などを書き換えたら `ac.layers = ls` で戻す。
- **体が 40 cm 浮いて脚が折れる。**
  - 自作の筋肉カーブのクリップには足の目標が入っていないので、足を IK で留めるとこうなる。
  - 足はアニメーションのままにして、`LateUpdate` で腰を回す・上げる。
- **表情のクリップにも体の値が入っている。** エディタで当てるときは、表情 → 体の順にする。
- **座りのアニメが床に沈む。** 座りを元にアニメを作るときは、元のクリップの設定 (腰の高さの基準) を写す。
- **バッチで撮った姿勢が最初のまま。** SkinnedMeshRenderer に `forceMatrixRecalculationPerRender = true` を入れないと、皮が最初の姿勢のまま写る。
- **耳がらせん状に回る。** 回転を足し続けていた。毎フレーム、休みの向きから回す。
- **指がばたつく。** 指のもじもじの位相を「時刻 × 速さ」で出していたので、速さが変わると飛んだ。位相は積んで出す。
- **手を振り続ける。** 「寄る → 喜ぶ」が繰り返されていた。1 回きりの動作 (手を振る・拍手・喜ぶ・指差し) は 3 秒で必ず戻す。
- **筋肉の値の向き。** この骨格では "Front-Back" の + は後ろ、"Down-Up" の + は上だった。手を届かせる計算の前に確かめる。

## 物理と接触

- **掴みで処理落ちした。** ConfigurableJoint の固定点で引くと、関節が暴れた。速度で引く方式 (上限つき) にする。
- **掴む表示で没入感が壊れる。**
  - 体に VRCPickup を付けると、表示・青い縁・振動が出る。
  - 骨に付けた見えない PhysBone を掴む所にする。揺れ物は外す (伸びてぽよぽよ揺れる)。
- **近づく・抱きしめるとラグドールになったり後ずさったりする。**
  - 倒れるのは強い時だけにする: 手が 7 m/s を超えたとき、または 0.45 m 以内で 3 m/s 以上で走ってぶつかったとき。
  - 下がるのは苦手な人からだけにする。
  - 叩く判定は「手そのものの速さ」(体から見た手の速さ。歩き・走りを含まない) にする。
  - 掴んでいる本人の手と、顔のそばの手は数えない。
- **頭・足の接触の位置がずれる。** 高さ 0 の球の接触は、位置がアバターの根元になることがある。位置は手の接触だけ信用する。
- **掴みが同期しない。** Instantiate で増やした PhysBone は、掴み・ポーズが同期しない。最初からシーンに置く。

## 同期と Udon

- **何も同期しなくなる。**
  - バッチで付けた U# は、同期の種類が既定の「連続」のまま保存されていた。
  - 手動のつもりの脳に配列を足したら、1 回の上限 (約 200 B) を超えた。
  - シーンを保存する前に宣言どおりにそろえ、構成の確認でも見る。
- **ネットワークイベントを受け取れない。** 受ける U# を `BehaviourSyncMode.None` にすると送れない。NoVariableSync にする。
- **ビルドが止まる。** `VRCObjectSync` は、手動同期の Udon と同じ物に付けられない。位置は脳の中で自分で同期する。
- **壁の文字が変わらない・透けて見える。**
  - TextMesh の文字は Udon から変えられない。UI Text を使う。
  - ワールドに置く文字は、奥行きを見る材質 (描く順 2450) にする。そうしないと髪の手前に透ける。
- **一括置換で入れた行の途中の `//` が、後ろのコードを飲み込む。**
  - 時定数 0 → NaN が網全体に広がった。別のファイルでは設定値が消えた。
  - 説明は別の行に書くか、`/* */` にする。

## 見た目・光・撮影

- **部屋の中から壁が見えない。** 外箱の面が外を向いていた (Blender は裏面も描くので気づかない)。裏返した面を足し、外向きの面は焼き込みから外す。
- **家具が黒くなる。** Blender で変形して作った家具は、自動の 2 番目の UV が崩れてライトマップが黒くなる。プローブで照らす。
- **家具とアバターが暗くなる。** 家具の箱の中のプローブは真っ黒になる。置かない。
- **目の周りがサングラス状に暗い。** 後処理の AO が、前髪の下に影を作っていた。キャラクターのいるワールドでは AO を使わない。
- **撮影が実際の画面より暗い。** ARGBHalf + ReadPixels の撮影は線形のまま保存される。ARGB32 + sRGB で撮る。
- **ClientSim の画面は明るさの基準にならない。** 後処理が効いていない。
- **子の付け替えが黙って失敗する。** FBX や部品のプレハブ (部屋、YamaPlayer) は、付け替える前にほどく。
- **ポスプロが VRChat で効かない。**
  - コードで足した設定は、`AddObjectToAsset` しないとファイルに残らない。
  - レイヤーは 22 にする。
