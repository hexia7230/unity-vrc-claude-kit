# 脳の作り方: NPC 用に縮めた「ハエの脳」

## 元にしたもの

- 論文: Shiu et al., "A Drosophila computational brain model reveals sensorimotor processing", Nature 2024
- コード: github.com/philshiu/Drosophila_brain_model (MIT)
- 中身: FlyWire の全脳結線を、そのまま漏れ積分発火 (LIF) の細胞で動かす。
- 結合の重み = シナプスの数 × 伝達物質の符号 (アセチルコリンは +、GABA とグルタミン酸は −)。

## Udon で回せる大きさに縮める

- **発火ではなく発火率にする**: `r += dt * (感度/時定数 * 入力 - (r - 安静値)/時定数)`。r は 0..1。
- **入力** = いつもの偏り + 感覚 + 一時的な刺激 + 揺らぎ + Σ 結合 × 発火率。
- **回し方**: 計算役 (オーナー) だけが 0.25〜0.5 秒ごとに回す。
- **大きさ**: 行動に関わる経路だけを、約 30 の「まとめ細胞」と約 120 結合にした。符号の決め方は元のモデルと同じ。
  - **感覚 10**: やさしく触れられる・乱暴にされる・迫ってくる・人がそば・見つめられる・食べ物・好きな人・苦手な人・ひとり・おもちゃ
  - **気分 8**: 快・不快・甘え・退屈・眠気・照れ・いらいら・覚醒 (ドーパミン・オクトパミンの持続、睡眠圧)
  - **中枢 4**: 報酬のドーパミン・罰のドーパミン・近づきたい・避けたい (PAM / PPL1、キノコ体の出力ニューロン)
  - **行動 8**: 寄る・下がる・びくっ・仕草・休む・歩き回る・遊ぶ・甘える (下行ニューロン)
- **行動の選び方**: 行動の細胞どうしは −0.3 で抑え合い、いちばん強いものが勝つ。
- **人ごとの好き嫌い** (キノコ体の学習にあたる): ふれあった直後、その人の値を「報酬のドーパミン − 罰のドーパミン」で少しずつ動かす。

## 使い方

- **行動**: 休む → うたた寝、寄る → 近づく、歩き回る → ソファ・窓・床、遊ぶ → ゲーム機、甘える → 喜ぶ。
- **仕草の間隔**: 仕草の細胞が強いほど短くする。
- **待機中の表情**: いちばん強い気分の細胞で決める。
  - 快 → 笑顔
  - 照れ → 赤面
  - 眠気 → まったり
  - 退屈 → じとっ
  - 不快 → しょんぼり
  - いらいら → ふんす
- **同じことばかりしない**: いまの行動を戻して入れる。寝ている・遊んでいる・歩き回っていることを、眠気・退屈に返す。
- **手足と表情の層へ**: 細胞から「動きのもと」8 つを作って同期する。

## 人格は値で決まる

- 甘えん坊: 甘えの安静値 0.35、報酬 → 甘え の結合を強く
- 照れ屋: 見つめられる → 照れ の感度 1.6
- 好奇心旺盛: 何もないと退屈がすぐ溜まる
- 怒ってもすぐ忘れる: いらいらの時定数 10 秒
- ちょっとさみしがり: ひとり → 不快
- 気まぐれ: 行動の細胞に揺らぎ 0.08
- おやつに弱い: 食べ物がいらいらを強く消す

## Unity の外で確かめる

C# の網の定義 (`BuildNet`) をそのまま読み取る node の模擬を書き、場面ごとに動かす。実例の結果:

- 撫でる 10 秒: 快 0.25 → 0.66、甘える 1.0
- つつく 3 回: いらいらは最大 0.38、15 秒で 0.1 に戻る
- 好きな人がそば: 寄る 0.8。苦手な人がそば: 下がる 0.6 → 0.8
- ひとり: 約 9 分ごとにうたた寝

必ず入れる安全策:
- 時定数が 0 なら補う。
- NaN になった細胞は安静値に戻す。編集ミスで、NaN が網全体に一度広がったことがある。

## ワールドの表示の言葉

内部の名前 (ハエ・キノコ体・下行ニューロンなど) は、ワールドの中に出さない。表示は「こころの回路」「好き / きらい」「行動」のような言葉にする。
