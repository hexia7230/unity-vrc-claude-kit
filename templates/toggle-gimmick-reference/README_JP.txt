ANTIGRAV - 反重力フィールド for VRChat
Version 1.0.0

================================================================
1. 概要
================================================================
Inspector でチェックした場所 (髪・スカート・リボン・しっぽなど、PhysBone で動いている部分) を、
メニュー ON の間だけ重力に少し逆らわせて、ふわっと持ち上げながらゆっくり「わさわさ」揺らすギミックです。
完全に逆立つのではなく、反重力フィールドの中に居るような揺れ方になります。

プレイヤーの移動や重力そのものには触りません。見た目だけです。
非破壊です。元のアバターのメッシュ・マテリアル・PhysBone には触らず、この Prefab を消せば元どおりになります。

================================================================
2. 動作環境
================================================================
- Unity 2022.3.22f1
- VRChat SDK (Avatars) 3.7 以降 (3.10.5 で動作確認)
- Modular Avatar 1.10 以降 (1.18.7 で動作確認)
- 揺らしたい部分が PhysBone で動くアバター

================================================================
3. 導入手順
================================================================
1) ANTIGRAV_vX.X.X.unitypackage をインポートします。
2) Assets/ANTIGRAV/Prefabs/ANTIGRAV.prefab をアバターのルート直下にドラッグします。
3) Inspector に、そのアバターの PhysBone が一覧で出ます。揺らしたい場所にチェックを入れます (「全部チェック」「全部外す」ボタンあり)。
4) そのままアップロードしてください。Expression Menu に「反重力」のトグルが追加されます (同期 1 bit)。

================================================================
4. 仕組み
================================================================
- アップロード時 (NDMF) に、チェックした PhysBone の Gravity を、ON のアニメーションで
  「-浮き + 揺れ × sin(時間)」の波で動かします。ゆっくり波打つ重力で、毛先がふわふわと上下に揺れます。
- 場所ごとに波の位相をずらしているので、全部が一斉に動くことはありません。
- OFF のアニメーションでは元の Gravity / Gravity Falloff に戻します。ON/OFF の切り替えは 0.6 秒かけて混ざります。

================================================================
5. Inspector の設定
================================================================
[対象]   PhysBone の一覧にチェック
[浮き方] 重力に逆らう強さ (初期値 0.08。0 で無重力のふわふわ、大きいほど上向き) /
         わさわさの大きさ (初期値 0.07) / 1 往復の秒数 (初期値 4.5) / 場所ごとの位相のばらつき (初期値 1)
[メニュー] メニュー名 / 最初から ON / 状態を保存する / パラメータ名

================================================================
6. 制限事項と注意
================================================================
- PhysBone の重力はアニメーションで値を書き換えています。VRChat の仕様変更で PhysBone の値がアニメーションから動かせなくなった場合は動きません。
- 揺れの見え方は、その PhysBone の Pull / Spring / Stiffness の設定に左右されます。固い設定の部分はあまり動きません。
- 「浮き」を大きくしすぎると髪が頭に刺さることがあります。その場合は値を下げるか、その場所のチェックを外してください。
- ON/OFF は他の人にも同期して見えます。揺れの位相は各クライアントで少しずれることがあります。
